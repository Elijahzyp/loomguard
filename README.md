# LoomGuard

Camera-based fabric defect detection system for knitting machines.

## Status
Phase 1A — algorithm validation on AITEX public dataset (woven fabric).
Phase 1B — real knitted fabric data collection (pending).

  results/                   # experiment outputs (gitignored)
